# Comprehensive Climate Indicators & Fields Reference Table
# جدول المرجع الشامل لجميع المؤشرات والحقول المناخية (82 مؤشر)

This reference table documents all 82 climate indicators generated by the **NASA POWER & Open-Meteo Climate Atlas Generator for ArcGIS 10.8**.

---

## 1. Administrative Fields (حقول الإدارة والبيانات الوصفية)

| Field Name | Type | Description (AR) | Description (EN) | Source / Meaning |
| :--- | :--- | :--- | :--- | :--- |
| `Source_ID` | LONG | المعرف الأصلي للنقطة | Original Feature ID | Unique station / sample ID |
| `Point_Lat` | DOUBLE | دائرة العرض (WGS84) | Latitude (degrees North) | WGS 84 (EPSG:4326) |
| `Point_Lon` | DOUBLE | خط الطول (WGS84) | Longitude (degrees East) | WGS 84 (EPSG:4326) |
| `Data_Start` | LONG | سنة بداية السلسلة الزمنية | Start Year of Time Series | Beginning year of climate normal |
| `Data_End` | LONG | سنة نهاية السلسلة الزمنية | End Year of Time Series | Ending year of climate normal |
| `Temporal` | TEXT | الدقة الزمنية للبيانات | Temporal Frequency | Monthly / Daily / Precalculated |
| `Interp_Meth`| TEXT | خوارزمية الاستيفاء المكاني | Spatial Interpolation Method | IDW / Kriging / Spline / Natural Neighbor |
| `Cell_Size` | DOUBLE | حجم خلية الراستر الأساسية | Base Raster Cell Size | Meters or converted degrees |
| `Wind_Cell` | DOUBLE | حجم خلية متجهات الرياح | Wind Grid Cell Size | Coarser spacing for arrows |
| `Status` | TEXT | حالة معالجة النقطة | Processing Status | `OK` or `FAILED` |
| `Error_Msg` | TEXT | رسالة الخطأ (إن وجدت) | Error Message if Any | Network or processing exception |

## 4. Drought & Aridity Module (`10_Drought_And_Aridity`) - 5 Fields
